Stacked notifications block the "Go to Cart" button

Duplicate stock alerts pile up over the main purchase button.

App
GjirafaMall
Platform
Web
Bug type
UI/UX
Severity
Medium–High
Status
Reported

Summary

When the cart stock is updated, the notification "Vlera e stokut i produkteve në shportë është përditësuar" appears several times. The copies stack vertically and spread down over the product controls, covering the main purchase button.

Steps to reproduce

  1. Open a product page on GjirafaMall.
  2. Trigger the cart/stock update action several times.
  3. Observe the notifications in the upper-right area.

Expected result

Only one notification is shown for the same action, duplicates replace the previous one, and notifications stay in their own area without covering buttons.

Actual result

Duplicate notifications stack on top of each other and cover the "SHKO NË SHPORTË" button and nearby quantity controls, making them hard or impossible to click.

Impact

Blocks a primary e-commerce action and can stop the user from proceeding to the cart.

Search result screens stack and overlap

Previous search results stay visible at the edge of the screen when navigating back.

App
Instagram
Platform
Mobile
Bug type
UI/Navigation
Status
Reported

Summary

After searching several terms and navigating back through them, previous search result screens stay in the view. Parts of the earlier result pages appear on the right side of the screen, side by side with the current one.

Steps to reproduce

  1. Search "baby", then go back.
  2. Search "dog", then go back.
  3. Search "catering".
  4. Navigate back through the previous searches.
  5. Observe the edges of the screen.

Expected result

A single search results screen updates with the new query and results. Going back returns to the search history.

Actual result

Each search keeps its own results screen. While viewing "dog" results, part of the "catering" screen is visible on the right; while viewing "baby", part of the "dog" screen remains.

Impact

A broken, split-screen layout that makes navigation confusing.

Follow status not updated after switching accounts

The video shows "Follow" for a creator the active account already follows.

App
TikTok
Platform
Mobile
Bug type
Functional
Severity
Medium
Status
Reported

Summary

After switching accounts while viewing a video, the follow button still shows the previous account's status. It only refreshes after opening the creator's profile.

Steps to reproduce

  1. Open TikTok with Account A, which does not follow the creator.
  2. Open a video from that creator.
  3. Switch to Account B, which already follows the creator.
  4. Check the follow status on the same video.
  5. Open the creator's profile and check again.

Expected result

The video screen immediately shows "Following" for Account B.

Actual result

The video still shows "Follow". The correct "Following" status appears only after opening the creator's profile.

Impact

The user sees incorrect account-specific data and may try to follow a creator they already follow.

Replying to a Memory exits the chat

After sending a reply, the user lands on the main Chats list instead of staying in the conversation.

App
Snapchat
Platform
Mobile
Bug type
Functional
Severity
Medium
Status
Reported

Summary

When replying to an old Memory from inside a chat, the reply is sent, but the app closes the Memory and the conversation and returns to the main Chats list.

Steps to reproduce

  1. Open a chat with a friend.
  2. Open an old Snap Memory from the conversation.
